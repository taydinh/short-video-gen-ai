# Football Assets Attribution

This directory contains flags and club crests/logos downloaded from Wikimedia Commons/Wikidata.

Each downloaded asset is tracked in `assets/football/index.json` with:
- `badge.sourceUrl`
- `badge.licenseName`
- `badge.licenseUrl`

If you add/replace assets manually, please also update `assets/football/index.json`.
